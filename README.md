## Paseo plugins

Plugins for [Paseo](https://paseo.sh). Install any of them with `paseo plugin install <repo URL>`.

- [Ask](https://github.com/puchkoff/paseo-ask): a floating window for quick questions, answered by Claude on the daemon.
- [Inbox](https://github.com/puchkoff/paseo-inbox): one screen for everything waiting on you, what is running, and what just finished.
- [Todo](https://github.com/puchkoff/paseo-todo): park tasks with a prompt and launch an agent from them later.
- [Log](https://github.com/puchkoff/paseo-log): a log that agents write to and you read, newest first.
- [System monitor](https://github.com/puchkoff/paseo-system-monitor): live CPU, memory, disk and network of the machine running the daemon.
- [Paste files into the composer](https://github.com/puchkoff/paseo-files): paste any file into an agent composer with Ctrl+V / Cmd+V.
- [Up arrow repeats last prompt](https://github.com/puchkoff/paseo-chat-up): press Up in an empty composer to get your latest prompt back.
- [Double-click rename](https://github.com/puchkoff/paseo-2click-rename): double-click a workspace or an agent tab to rename it.

### Paseo plugins

Small additions to [Paseo](https://paseo.sh). Install any of them with `paseo plugin install <repo URL>`.

- [Ask](https://github.com/puchkoff/paseo-ask): quick questions in a floating window, answered by Claude on the daemon.
- [Inbox](https://github.com/puchkoff/paseo-inbox): everything waiting on you, what's running, and what just finished.
- [Todo](https://github.com/puchkoff/paseo-todo): park tasks with a prompt and start an agent from them later.
- [Log](https://github.com/puchkoff/paseo-log): a log agents write to and you read, newest first.
- [System monitor](https://github.com/puchkoff/paseo-system-monitor): CPU, memory, disk and network of the daemon's machine.
- [Paste files](https://github.com/puchkoff/paseo-files): paste any file into the composer with Ctrl+V or Cmd+V.
- [Up arrow](https://github.com/puchkoff/paseo-chat-up): press Up in an empty composer to get your last prompt back.
- [Double-click rename](https://github.com/puchkoff/paseo-2click-rename): double-click a workspace or an agent tab to rename it.

### Claude Code skills

- [git-diff-html](https://github.com/puchkoff/git-diff-html-skill): shows `git diff` as an HTML page you can share, with a file tree, a full-file view and review comments on lines.

### CMUX

Tools for [CMUX](https://cmux.com), a free, open-source macOS terminal for AI coding agents. Both plug into Claude Code.

- [cmux-mcp](https://github.com/puchkoff/cmux-mcp): MCP server for the CMUX CLI. Lets Claude Code drive CMUX panes, workspaces, terminal input and the built-in browser.
- [cmux-session-cleaner](https://github.com/puchkoff/cmux-session-cleaner): Claude Code plugin that removes dead sessions from CMUX's session file, which CMUX never prunes and keeps in memory.

### Python

- [pytoony](https://github.com/puchkoff/pytoony): a Python package and CLI that converts between JSON and TOON, a compact format for passing structured data to LLMs with 30–60% fewer tokens than JSON.
